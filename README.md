
# SavorIt - Modern Food Ordering Platform

## 🚀 One-Command Local Startup (VS Code)

### 1. Install & Start
Open your VS Code terminal (`` Ctrl+` ``) and run:

```bash
npm install && npm start
```

### 2. Open the App
Visit: **[http://localhost:5000](http://localhost:5000)**

## 🛠️ Tech Highlights
- **Server**: Single Node.js server for both API and UI (Zero CORS).
- **Database**: Real-time SQLite persistence in `database.db`.
- **Frontend**: React transpiled in-browser via Babel for zero-build dev.
